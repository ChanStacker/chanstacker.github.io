## Hi, I'm ChanStacker 👋

I'm a senior staff engineer on a trading platform, and I've spent many years building
software for the investment banking and hedge fund world: trade capture, position keeping,
P&L, and the plumbing that moves data between them.

These days a lot of my time goes on architecture and technical direction: how the pieces
of a platform fit together, how it behaves under load and when things go wrong, and helping
other engineers make good decisions. I still like getting my hands dirty, and that's where
most of this blog comes from.

This blog is my notebook. When I work something out, like a Kafka offset quirk, a slow SQL
query or a Kubernetes networking puzzle, I write it down so future-me (and hopefully you)
doesn't have to work it out again.

### What I work with

- **Backend:** C# / .NET, Entity Framework, Blazor, log4net
- **Data:** SQL Server (performance tuning, T-SQL), processing very large files
- **Messaging & scheduling:** Kafka, Control-M
- **DevOps:** Docker, Kubernetes, Azure DevOps, Linux
- **Frontend (when I must):** CSS Grid, Bootstrap
